# 📊 HR Analytics Project – Power BI Dashboard

## Overview
This project focuses on analyzing HR employee data using Power BI to gain insights into workforce distribution, salary structure, and employee demographics. The analysis is performed using a CSV dataset and visualized through an interactive Power BI dashboard for better decision-making.

---

## Objectives
- Analyze employee distribution across departments  
- Understand salary trends and ranges  
- Study workforce demographics such as age, gender, and marital status  
- Build an interactive HR analytics dashboard using Power BI  

---

## Dataset
**File Used:** HR_Analytics.csv  

The dataset includes:
- Employee information (Age, Gender, Marital Status, Education)
- Job and department details (Department, Job Role, Job Level)
- Salary and compensation data (Monthly Income, Salary Slab, Rates)
- Work-related factors (Overtime, Satisfaction Levels, Work-Life Balance)

---

## Power BI Dashboard Features
- KPI Cards showing:
  - Total Employees
  - Average Salary
  - Minimum Salary
  - Maximum Salary
- Visualizations:
  - Employees by Age Group
  - Employees by Marital Status
  - Gender Distribution
  - Department-wise Employee Count
- Interactive filters for Department and Employee Type (Past / Present)

---

## Key Insights
- Majority of employees fall in the 26–45 age group  
- R&D department has the highest number of employees  
- Male employees are higher in number compared to female employees  

---

## Conclusion
This project demonstrates the use of Power BI for HR analytics by converting raw employee data into meaningful insights. The dashboard helps HR teams and management understand workforce patterns and supports data-driven HR planning.
